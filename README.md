# Fundamentos de Computación Paralela y Distribuida (2026-2)

Este repositorio contiene los talleres, laboratorios, proyectos y ejercicios desarrollados en el curso de **Fundamentos de Computación Paralela y Distribuida** durante el periodo académico **2026-2**.

---

## 📌 Descripción del Curso

El objetivo de la materia es adquirir competencias en programación concurrente, paralela y distribuida, aplicando modelos de memoria compartida y distribuida mediante lenguajes como C/C++, así como herramientas y librerías estándares del sector (OpenMP, MPI, hilos, etc.).

---

## 📁 Estructura del Repositorio

La organización del código y los materiales está estructurada en los siguientes directorios principales:

```text
.
```

---

## 🛠️ Herramientas y Lenguajes

- **Lenguajes:** C / C++
- **Compilador Recomendado:** `clang` / `gcc`
- **Entorno de ejecución:** Windows / PowerShell (Soporte para `scanf_s` y estándares C99+)

---

## 💻 Instrucciones Generales de Compilación

Para compilar cualquiera de los talleres en lenguaje C:

```bash
clang <nombre_archivo>.c -o <nombre_ejecutable>.exe
```

Ejecución en entorno Windows/PowerShell:
```powershell
./<nombre_ejecutable>.exe
```
